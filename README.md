# Portfolio asset archive

This branch stores original images and local SVG icons that are not used by the current application.

The complete application, configuration, documentation, and active assets are on the [master branch](https://github.com/Ragraze/portfoliov1/tree/master).

## Contents

- `public/certificates/`: 27 original JPG, JPEG, and PNG certificate images.
- `src/assets/images/`: 16 original JPG and PNG project, profile, and decorative images.
- `src/assets/icons/`: 43 unused local SVG icons.

The 86 assets retain their original paths and file contents. The application uses WebP images, dependency icons, and seven active local SVG icons kept on `master`.

## Using the application

```sh
git clone --branch master https://github.com/Ragraze/portfoliov1.git
cd portfoliov1
npm ci
npm run dev
```

## Asset rights

Certificates, personal photographs, company materials, project screenshots, and brand logos remain subject to their respective owners' rights. These files are retained as portfolio backups; the source-code MIT license does not grant rights to these assets.
